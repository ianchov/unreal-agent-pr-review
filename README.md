# unreal-agent-pr-review

Retired.

This repository offered a pull request review workflow built on
[ianchov/unreal-agent-pr-review-action](https://github.com/ianchov/unreal-agent-pr-review-action).
Both public repositories were retired. The review logic now lives in a private
repository that runs the reviews on its own machines, with its own provider key.

Nothing is offered here any more. The workflows, the workflow templates and the
dependency bot configuration that made the offer are removed.
